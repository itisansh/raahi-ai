# Raahi AI

面向印度各地旅行的协作规划应用。支持共享行程、地图、费用记录，以及经过确认后保存的 AI 行程建议。

目的地不限于北阿坎德邦。可以规划拉贾斯坦、喀拉拉、果阿、东北地区、喜马拉雅山区等印度目的地。示例行程不代表实时报价或已确认的预订。

技术栈：React/Vite、TypeScript、Express、MongoDB/Mongoose 和 Better Auth。
