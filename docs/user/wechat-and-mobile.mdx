---
title: Mobile and PWA
description: Use Raahi AI in a mobile browser or install its PWA.
---

Open Raahi AI in your mobile browser and sign in with email or configured Google
login. Use the browser’s install or Add to Home Screen action for app access.

WeChat sign-in and the Mini Program have been retired. If WeChat was your only
sign-in method, arrange account recovery before retirement in a live deployment.
Existing accounts and trips are preserved.
